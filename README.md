CRT-2026: A Full Stack Java Training Repository
This repository, maintained by himanshuwalde, contains a comprehensive curriculum for Full Stack Java development, covering fundamental programming concepts, Data Structures and Algorithms (DSA), SQL, and Spring Boot
.
Repository Overview
The content is organised day-by-day, tracking the progress of a training program. It primarily uses Java (83.3%) and HTML (16.7%)
.
Curriculum Breakdown
Phase 1: Java Basics & Data Structures
Day 1: Basics - Includes concepts like recursion (e.g., Sum of n Natural Numbers)
.
Day 2: Arrays | Searching & Sorting - Practical applications like the Two Sum problem
.
Day 3: Linked List - Operations such as finding Min/Max in a Linked List
.
Day 4: Stack & Queue - Implementation of Stacks using Linked Lists
.
Day 5: Tree - Implementation and operations on Binary Trees
.
Day 6: Graphs - Introduction to Graph theory and implementation
.
Day 7: HashMap - Advanced operations like reversing a HashMap
.
Phase 2: SQL and Database Management
Day 8-9: SQL Foundations - Covers DML (Data Manipulation Language) and DDL (Data Definition Language) commands
.
Day 11: SQL Operators & Functions - Usage of various SQL operators and functions
.
Day 12: SQL Predicates - Working with predicates for data filtering
.
Day 13.1: Integrity Constraints & Joins - Detailed look at SQL Joins and database integrity
.
Day 13.2: SQL Project - A practical project applying SQL concepts
.
Phase 3: Advanced Topics & Projects
Day 10: CRT Test 1 - Assessments covering topics like Insertion Sort
.
Day 14-15: Practice Questions - Competitive programming style questions (e.g., Monk and Rotation, Richest Customer Wealth)
.
Day 16-19: Spring Boot Project - Development of a project using the Spring Boot framework
.
Day 20: Collections - Deep dive into the Java Collections Framework
.
Day 21: Interview Questions - Preparation material for technical interviews
.
Getting Started
To explore the code for a specific day:
Navigate to the directory of interest (e.g., Day-3 Linked List).
Open the relevant .java or SQL files to view the implementation.
